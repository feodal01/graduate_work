# Схемы сценариев сервиса «Биллинг»

В каталоге находятся исходники PlantUML (`*.puml`) и отрендеренные изображения (`*.png`) по всем пользовательским, административным и системным сценариям из раздела 4 [`docs/billing/tz.md`](../../billing/tz.md).

Каждая sequence-диаграмма построена в два уровня:
1. **Сверху** — прямой основной сценарий (Happy Path) без вложенных ветвлений.
2. **Снизу** — отдельные компактные блоки краевых случаев и сбоев зависимостей.
