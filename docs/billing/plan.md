Документ раскрывает раздел 8 [ТЗ](tz.md): фичи `FEAT-01`–`FEAT-04` разбиты на сторис из раздела 4, сторис — на задачи с оценкой в часах, зависимостями и отметкой риска. Диаграмма Ганта: [`15-gantt-plan-by-stories.png`](../diagrams/billing/15-gantt-plan-by-stories.png) (исходник [`.puml`](../diagrams/billing/15-gantt-plan-by-stories.puml)).

## Допущения планирования

- Один исполнитель (`2.3`), задачи выполняются последовательно в порядке номеров `T-NN`.
- Рабочая неделя — понедельник–суббота по 8 ч (48 ч); воскресенье — выходной и день демо. Суббота — контрольная отсечка прогресса (`8.4`).
- Оценка задачи включает модульные и интеграционные тесты к ней; сквозные E2E- и стаб-тесты вынесены в стабилизацию.
- Рисковые задачи (⚠) — интеграция с API ЮKassa и координация воркера `outbox_tasks` (`8.4`). При срабатывании риска сначала расходуется резерв `T-41`, затем применяется очередь сокращения объёма из `8.2`.
