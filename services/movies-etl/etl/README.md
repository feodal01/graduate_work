# Схема индекса `movies`

Файл `es_schema.txt` содержит исходную схему индекса для справки. Movies ETL не загружает этот файл во время работы.

Рабочий mapping находится в `postgres_to_es/pipelines/loader/mapping.py`. Он задаёт строгую схему документов, анализатор русского и английского текста и поля для фильмов, жанров, режиссёров, актёров и сценаристов.

В едином проекте `elasticsearch-init` восстанавливает готовый индекс из снапшота до запуска Movies ETL. Если ETL работает без этого индекса, loader создаёт индекс с рабочим mapping перед первой загрузкой документов.

Поле `creation_date` хранит дату выпуска фильма. Внешний сервис может использовать эту дату при проверке политики доступа.
